CHECKPOINT/RESUME
- Schema version 1 under spec/schemas/w5_training_artifacts.schema.json.
- Completed-epoch checkpoints only. Incomplete epochs replay from the latest authenticated completed epoch.
- A checkpoint is immutable and named by epoch; publication is temporary write, flush, fsync, atomic rename without replacement, directory fsync, exact-byte SHA-256 sidecar publication, then latest-pointer publication.
- Resume authenticates sidecar SHA/length before torch.load and then exact schema, role/eligibility, source/config/data/profile/model/ratio/k/seeds/SNR/lambda/optimizer/scheduler/scaler/counters and checkpoint predecessor.
- Corrupt or incompatible latest state is HOLD. There is no silent fresh start and no older-checkpoint fallback.
- Keyed/stateless streams have no serialized mutable RNG state. GradScaler state is serialized when enabled. No other sequential RNG is consumed by the trainer.
