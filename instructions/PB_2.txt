## Outage policy

Read from `spec/params.generated.yaml`:

    baseline.outage_policy               = frozen_constant_class_selected_on_validation
    baseline.outage_class_selection      = highest_validation_accuracy_constant_prediction
    baseline.outage_class_tie_break      = lowest_class_index
    baseline.outage_class_frozen_before  = test
    baseline.outage_policy_sensitivity   = keyed_uniform_random_label
    baseline.outage_rng_key              = [split_manifest_hash, stable_sample_id, channel_seed,
                                            purpose=outage_label]

Requirements for selecting the constant class:

  * uses **validation labels only** — never test;
  * applies the configured tie-break (lowest class index);
  * is reproducible from the manifest alone;
  * is frozen before test is ever opened;
  * **never assumes `1 / n_classes` as the outage accuracy.** The outage accuracy is the *measured*
    validation accuracy of the frozen constant prediction, which for an imbalanced or even a
    balanced-but-finite split is not exactly `1/n`.

Provide a clean interface plus a bounded validation proof (a small artifact showing the selected
class, the measured accuracy, and the tie-break path taken). Do not open the test split.

Also implement the configured sensitivity variant (`keyed_uniform_random_label`) behind the same
interface, keyed per `baseline.outage_rng_key`, so PB_3 and later G-8 work can compare against it.

Persist the selection result to disk as a small committed artifact (the bounded validation proof
above serves this purpose) rather than recomputing it on every import. That makes it both
reproducible and crash-durable.

## Bounded executions for this phase

Run only:

  * a small CIFAR-10 plumbing smoke (extends PB_1's);
  * a **bounded** Imagenette validation subset — a few dozen images at one or two SNR points, not
    a sweep;
  * a high-SNR successful round trip producing a complete record set;
  * a forced decode-failure case producing an outage record with the correct `outage_reason`;
  * a keyed-noise equality test against the shared channel path.

Do not treat smoke accuracy as an experimental result. State the sample size next to every number.

The bounded Imagenette subset is the most expensive thing in this phase. Mark B2.6 `in-progress`
and commit that before starting it. Have the runner write its output incrementally to
`results/baseline/w4/` rather than accumulating in memory and writing once at the end — a run
killed at 80% should leave 80% of its rows on disk, and the runner should be able to resume from
what is already there rather than restarting.
