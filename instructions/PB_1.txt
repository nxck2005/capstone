## Objective

Implement the classical arm's end-to-end path from a canonical source image to a decoded image plus
a decode/outage verdict, reusing existing modules rather than duplicating them.

Target pipeline segment for this phase:

    canonical source image
    → configured downsample
    → JPEG 2000 budget search
    → exact packet plan
    → TB CRC
    → code-block segmentation and CRC
    → filler and rate matching
    → modulation bit interleaving
    → BPSK/QPSK/16-QAM mapping
    → shared project AWGN channel
    → soft demapping
    → LDPC decode
    → CRC check and decode-failure/outage classification
    → JPEG 2000 decode
    → configured upsample

The classifier, metrics, records and aggregation are PB_2's job. B1 should return a structured
result object that PB_2 can consume.

## Budget and accounting requirements

For every invocation of the pipeline:

  * `k` complex channel uses must be **exact** — not approximately, not rounded.
  * Channel bits must equal `k × Qm` for the selected modulation.
  * The source codestream, container bytes included, must not exceed payload capacity.
  * Residual payload slack must be counted as filler, never silently dropped.
  * TB CRC, per-code-block CRC, filler bits and rate-matched bits must reconcile exactly against
    the packet plan. Emit this reconciliation as structured data, not as a log line.
  * Partial final code blocks must be supported.
  * Realized per-packet symbol energy must be computed and returned.
  * Symbol-domain PAPR must be computed and returned (`channels.power.symbol_papr_db`).
  * Per-packet power rescaling is **prohibited**. Normalization is the fixed constellation
    normalization only; do not renormalize a realized packet to unit energy.

## Failure taxonomy — three distinct outcomes

These must be distinguishable in the returned result and must never be collapsed:

  1. **Structural infeasibility** — no valid TS 38.212 packetisation exists for the requested
     `(k, modulation, rate)`. Detected before any encoding.
  2. **Codec infeasibility** — a packetisation exists, but JPEG 2000 cannot produce a codestream at
     or below the payload budget for this image at any configured axis.
  3. **Decode failure** — transmission occurred and CRC failed.

A silently skipped infeasible case is a defect. Every invocation returns a verdict.

## Bounded executions for this phase

Run only these; they are plumbing checks, not experiments:

  * a small CIFAR-10 plumbing smoke (a handful of images, validation split);
  * at least one case per modulation (bpsk, qpsk, qam16);
  * at least one multi-code-block case;
  * the expected structural-infeasibility case;
  * a forced codec-infeasibility case;
  * a forced decode-failure case (very low SNR);
  * a high-SNR successful round trip;

Do not treat any accuracy number from these as an experimental result. Do not run a validation
sweep.

individually but tedious to redo as a set.

## Keyed noise

Noise must be counter-based and keyed, never sequential. Per `analysis.noise_id_key`, the identity
is: dataset_version, split_manifest_hash, stable_sample_id, test_snr_db, channel_seed, channel, k,
block_index, rng_purpose. Changing batching, row order, or the other system's control flow must not
change a row's keyed noise — there is an existing precedent test in
`tests/test_keyed_complex_noise.py` and `tests/test_artifact_rng.py`; follow it.
