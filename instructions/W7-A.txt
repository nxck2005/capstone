W7-A G-4 PRE-EXECUTION CONTRACT
Frozen: owner-authorized final W7-A, before any W7 scientific optimizer step or lambda result.
Normative source: spec/SPEC.md remains authoritative; this contract freezes only the pre-result operational semantics required by SR-9, SR-10, SR-11, SR-12, SR-16 and G-4.

PURPOSE
Prepare one mechanically closed five-pilot lambda campaign. W7-A is engineering and preregistration only. It does not authorize W7-B scientific execution.

SCOPE BOUNDARY
The only real-data optimizer steps permitted during W7-A are one complete Imagenette-160 training epoch for a Pascal workload profile. That profile is NON_SCIENTIFIC, has zero G-4 coverage, cannot select lambda, cannot be promoted to W8 or test, and is not a scientific candidate. No validation inference is performed by the profile. There is no W7 scientific optimizer step, lambda candidate result, G-4 adjudication or lambda selection in W7-A.

FROZEN G-4 PROTOCOL
- Dataset: imagenette160, training split for training and the complete committed 1,000-image validation split for selection and metrics.
- Calibration ratio: params.learned_system.lambda_calibration_ratio, resolved through params.bandwidth.headline_ratio to r_1_6.
- Lambda grid and execution order: [0.0, 0.1, 0.3, 1.0, 3.0], exactly in that order. The adjudicator selects by numeric lambda, not traversal order.
- One compound seed pair (train_seed=0, channel_seed=0), shared by every candidate.
- Training SNR and checkpoint-selection calibration SNR: 7 dB, from the frozen parameters.
- PSNR evaluation SNR: 15 dB, from the frozen parameters.
- Accuracy tolerance: 1.0 percentage point, applied as a fraction of 0.01.
- Primary PSNR floor: 20 dB. Relaxed PSNR floor: 16 dB.
- Architecture, objective, optimizer, scheduler, AMP, keyed augmentation, keyed order, keyed channel noise, power normalization and task head are the current frozen DJSCC implementation and AM-91 recipe.

CHECKPOINT SELECTION
After each completed and durably published epoch, evaluate top-1 on the complete validation split at 7 dB. Metric is count-derived top1_accuracy, mode=max, tie-break=earliest epoch. PSNR never participates in checkpoint selection. The selected checkpoint is independently reloaded and its 7 dB result reauthenticated before its 15 dB PSNR/PAPR evidence is emitted.

VALIDATION SEMANTICS
No augmentation, no dropping, stable manifest order, explicit validation batch size 32, and no test access. Channel noise is generated by the keyed channel_noise identity for each stable validation ID, ratio, SNR and channel seed; the same intended per-image noise identity is used for every lambda candidate. The denominator is all 1,000 committed validation images. Test loading is structurally rejected.

PSNR AND PAPR
Reconstruction is RGB CHW against the canonical target tensor, clipped under params.preprocessing.reconstruction_clipped_before_metrics, with configured data_range (currently 1.0). Per-image MSE is the mean over all RGB pixels. Per-image PSNR is 10*log10(data_range^2/MSE); MSE=0 is represented as the JSON string "inf", which compares as positive infinity for floor decisions and is never emitted as non-finite JSON. Aggregate PSNR is the arithmetic mean over the complete denominator. PAPR is symbol-domain per-image PAPR followed by an arithmetic mean over the same complete denominator.

DECISION
Let A0 be selected-checkpoint validation top-1 for lambda=0. A candidate is accuracy-qualified iff candidate_top1 >= A0 - 0.01. PRIMARY chooses the numerically smallest accuracy-qualified lambda with PSNR >= 20 dB. Only if none exists, RELAXED chooses the numerically smallest accuracy-qualified lambda with PSNR >= 16 dB. If neither set is non-empty, G4 is HOLD and DEC-2 reversal/replanning is required; no lambda is invented. W8 final multi-seed training is prohibited before this closes.

PROFILE AND CUSTODY
All future W7 model-facing science is bound to confessor_pascal_cu126 and one exact physical Pascal GPU UUID. The owner-mandated ladder tries GTX 1080 Ti GPU-00214b86-48e7-fcf0-bf46-575fa7f85b6b first, then TITAN Xp GPU-46acd0f2-2ff5-1a43-cac9-2ae20e56dc9a only after a hard failure. Effective batch is 32; physical/accumulation ladder is 32/1, 16/2, 8/4, 4/8, 2/16. Validation batch is frozen at 32. The selected profile must process all 8,469 training IDs exactly once, include the final partial batch, publish a checkpoint, and conservatively project every one-lambda 100-epoch run under params.compute.max_wall_clock_hours_per_run (currently 4 hours).

LOCK
A single host-global Linux flock is held by one process for the entire future five-lambda campaign, not merely one candidate or checkpoint. Metadata is observational and records campaign ID, host, PID, source commit, execution image, GPU UUID and acquisition time; the open kernel-owned descriptor is authoritative. Process death releases the lock. A stale lock inode or metadata file does not own it.

CHECKPOINT AND RESUME
Every W7 checkpoint is immutable, SHA-256 identified, atomically published with an authenticated sidecar and latest pointer, and contains compact model/optimizer/scheduler/scaler state plus lineage. Detailed epoch and selected-validation rows are companion records, not recursively copied into later checkpoints. Runtime storage is O(number of epochs) checkpoints plus O(number of epochs) compact records. Incomplete execution replays only from the latest authenticated completed epoch. A corrupt or incompatible latest state is HOLD; no older silent fallback is permitted. W7 pilot checkpoints are eligible only for their own G-4 candidate evidence, never W8 initialization or test. Profile and W5 checkpoints are ineligible for G-4.

LAUNCH BOUNDARY
The detached launcher is implemented but must not be run during W7-A. It will authenticate a separately committed execution authorization, W5/W6, source and profile lineage, acquire the campaign lock, run the five candidates sequentially, and publish campaign completion without adjudicating G4 or changing lambda_core. W7-A terminal completion must state: scientific execution authorization = ABSENT.
